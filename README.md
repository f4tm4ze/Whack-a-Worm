# Whack-a-Worm
A chicken-themed whack-a-mole style arcade game. Click worms before they hide!

## Features
- 3x3 grid with worm holes
- 30-second time limit
- Three difficulty levels: Normal, Fast, Insane
- Persistent high score (localStorage)
- Custom chicken cursor
- Sound effects
- Responsive design

## Difficulty Levels
- **Normal**: Worm every 1.0 sec, hides in 0.8 sec
- **Fast**: Worm every 0.6 sec, hides in 0.55 sec  
- **Insane**: Worm every 0.35 sec, hides in 0.35 sec

## How to Play
1. Select difficulty level
2. Click RESET to start
3. Click worms to score points
4. Beat the high score within 30 seconds
